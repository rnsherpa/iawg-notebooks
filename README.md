# IAWG Notebooks

Notebooks to reproduce analyses from the IGVF Integrative Analysis Working Group via the IGVF Catalog/Portal API

## Contributions

(TEMP)

Clone/pull the repository, then create a personal directory `{username}/`. Add notebooks under `{username}/notebooks` and plots under `{username}/plots`.

Saved plots should be at least 300 DPI and in png/svg format.
